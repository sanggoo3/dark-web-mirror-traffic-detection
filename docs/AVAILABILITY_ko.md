# 논문용 Data Availability / Code Availability

## Data Availability

본 연구의 최종 성능 평가에 사용한 전처리 데이터셋 `direction526-20261101`은 GitHub 저장소 https://github.com/sanggoo3/dark-web-mirror-traffic-detection 의 `paper-20261101` 태그에 공개하였다. 공개 데이터는 4,600개 세션의 direction-only 시퀀스와 보조 실험용 상대 시간·통계 특징을 포함한다. 원래 URL·도메인과 IP 주소 등은 제거하고, 동일 사이트 및 도메인 그룹의 관계를 보존하는 가명 식별자로 대체하였다. 세션·사이트·도메인 그룹 배정, 두 평가 방식의 외부 및 내부 분할 인덱스, 프로토콜 필터, 시퀀스 길이, 절단·오른쪽 제로 패딩 규칙과 실험 설정을 함께 제공한다. 정확한 데이터 버전과 파일별 SHA-256은 `data/DATASET_VERSION.json`에 명시하였다. 원시 PCAP/PCAPNG는 개인정보 및 보안상의 이유로 공개하지 않는다. 따라서 공개 자료만으로 모델 실험과 기록된 처리시간의 재집계는 가능하지만, 원시 캡처를 이용한 전처리 처리시간의 독립적인 재측정에는 별도로 보유한 캡처가 필요하다.

## Code Availability

논문에 보고한 실험의 모델 구현, 하이퍼파라미터 탐색, 학습, validation 기반 임곗값 선택, 고정된 test 평가, 통계 집계 및 처리시간 측정 코드는 동일 GitHub 저장소의 `paper-20261101` 태그에 공개하였다. 실행 환경, 재현 명령과 표별 실험 대응 관계를 문서화하였으며, 보고값의 검증을 위한 튜닝 기록·예측값·가명화된 처리시간 기록을 제공한다. 코드에는 MIT 라이선스를, 데이터·결과·설정·문서에는 CC BY-NC 4.0 라이선스를 적용한다. 과거 `v1.0.0`은 현재 수정 논문의 재현 버전이 아니므로 혼용하지 않는다.

## 제출 전 반영할 점

위 문안은 `paper-20261101` 태그가 원격 저장소에 실제 게시된 뒤 사용한다. Git 태그와 해당 커밋 해시를 함께 인용하면 버전을 더욱 명확히 고정할 수 있다. 최신 branch만 인용하지 않는다. 교정 데이터에 맞는 Table3(a) 값은 `MANUSCRIPT_CORRECTIONS.md`에 별도로 제시하였다. 공개 데이터는 가명화된 것이며, 외부 정보와의 결합을 통한 재식별 가능성까지 완전히 제거했다고 주장하지 않는다.
